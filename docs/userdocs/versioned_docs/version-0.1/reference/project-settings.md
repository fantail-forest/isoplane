# Project settings

The MSBuild properties an application's project can set to change how the Isoplane SDK builds it. Names, defaults and descriptions are generated from the SDK's build files, for the source version used to build this documentation.

## Setting a property

Add the property to a `<PropertyGroup>` in the application's project file, the `.csproj`:

```xml
<PropertyGroup>
  <IsoplaneAnalyzeDependencies>true</IsoplaneAnalyzeDependencies>
</PropertyGroup>
```

A project created from an Isoplane template already has these properties in its project file, commented out.

To set a property for every project in a repository, put the same `<PropertyGroup>` in a `Directory.Build.props` file at the repository root. To set it for one build only, pass it on the command line:

```bash
dotnet build -p:IsoplaneAnalyzeDependencies=true
```

## Properties

### `IsoplaneAnalyzeDependencies`

Default: `false`.

Set to `true` to inspect the assemblies of NuGet packages as well, and report the thread starts ([`ISOPLANE1002`](error-codes.md#isoplane1002)), synchronous waits ([`ISOPLANE1003`](error-codes.md#isoplane1003)) and, when `IsoplaneWarnOnNativeImports` is on, native imports ([`ISOPLANE1001`](error-codes.md#isoplane1001)) found in them. When it is `false` the build reports these only for the application's own project and the projects it references.

### `IsoplaneWarnOnNativeImports`

Default: `false`.

Set to `true` to report each native import an inspected assembly declares, as [`ISOPLANE1001`](error-codes.md#isoplane1001), except imports of functions the runtime provides, such as SQLite's. It is off by default because a declaration alone does not show that the native call will be reached.

## Standard .NET properties

The warnings these properties produce also follow the ordinary .NET properties `NoWarn`, `WarningsAsErrors`, `TreatWarningsAsErrors` and `WarningsNotAsErrors`. [Control compatibility warnings](../how-to/run-and-rebuild.md#control-compatibility-warnings) shows how to use them, and [Error codes](error-codes.md) explains each warning.
