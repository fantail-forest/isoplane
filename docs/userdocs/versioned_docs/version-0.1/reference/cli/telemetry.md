# isoplane telemetry

Manage anonymous usage data. ISOPLANE_TELEMETRY_OPTOUT=1 or DO_NOT_TRACK=1 also disables it; ISOPLANE_TELEMETRY_DEBUG=1 prints events without sending them.

```bash
isoplane telemetry <command>
```

| Command | Description |
| --- | --- |
| [`isoplane telemetry status`](#isoplane-telemetry-status) | Show telemetry status. |
| [`isoplane telemetry enable`](#isoplane-telemetry-enable) | Enable anonymous usage data. |
| [`isoplane telemetry disable`](#isoplane-telemetry-disable) | Disable anonymous usage data. |

## isoplane telemetry status

Show telemetry status.

```bash
isoplane telemetry status
```

## isoplane telemetry enable

Enable anonymous usage data.

```bash
isoplane telemetry enable
```

## isoplane telemetry disable

Disable anonymous usage data.

```bash
isoplane telemetry disable
```
