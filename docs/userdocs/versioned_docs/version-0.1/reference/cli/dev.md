# isoplane dev

Run a local application. Launch settings supply the port and environment; --port overrides the port.

```bash
isoplane dev [options]
```

| Option | Description |
| --- | --- |
| `--project <project>` | Project directory (default: current directory). ISOPLANE_TARGET_DIR moves generated files outside it. |
| `-c, --configuration <configuration>` | Build configuration (default: Debug). |
| `--port <port>` | Local HTTP port (0–65535). |
| `--launch-profile <launch-profile>` | Profile from Properties/launchSettings.json. |
| `--settings <settings>` | JSON object of application settings for the session, such as {"Section:Key":"value"}; overrides User Secrets and the launch profile. Isoplane.Testing uses it. |
| `--no-launch-profile` | Do not load a launch profile. |
| `--no-watch` | Do not watch for source changes. |
| `--no-build` | Use compiled assemblies; requires --no-watch. |
| `--debug` | Preserve the debugger connection across requests and rebuilds. |
| `--shutdown-on-stdin-close` | Stop when standard input closes. |
| `--json` | Write machine-readable JSON. |
