# TraceExport.FlushAsync method

Sends the spans that have ended so far, including those of requests still running, and waits until every export started before it has been answered.

```csharp
public Task<bool> FlushAsync(CancellationToken cancellationToken = default)
```

| parameter | description |
| --- | --- |
| cancellationToken | Stops the wait; exports already started still finish. |

## Return Value

Whether the endpoint accepted every export it waited for.

## Exceptions

| exception | condition |
| --- | --- |
| OperationCanceledException | *cancellationToken* was cancelled. |

## Remarks

Spans are otherwise held until their request's span ends. Flush first when a request produces many spans, or when it should not end before its telemetry has been sent.
