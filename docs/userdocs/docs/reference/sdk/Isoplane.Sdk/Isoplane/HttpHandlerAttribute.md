## Remarks

Declare it as `Task<Response> HandleAsync(Request request)`, optionally with a second [`Ctx`](./Ctx.md) parameter. Take a [`StreamingRequest`](./StreamingRequest.md) in place of the [`Request`](./Request.md) to read the body as it arrives. An application has exactly one; the build fails otherwise. Instances may be reused or evicted between requests, so do not rely on state retained in memory or on work continuing after the response.
