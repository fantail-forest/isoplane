# RuntimeConfiguration class

The settings Isoplane supplies to the application, such as connection strings and credentials, for an application written without ASP.NET.

## Remarks

An ASP.NET application does not need this type. `IsoplaneHosting.CreateBuilder` adds the same settings to `builder.Configuration`, so read them through `IConfiguration`.

In local development the settings come from the project's User Secrets and the `environmentVariables` of its launch profile, the second overriding the first, and a sandbox test can add its own. [Supply local development settings](../../../../how-to/local-settings.md) describes each source. The application sees none of the machine's environment variables.
