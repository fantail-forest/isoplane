# RequestHead.Aborted property

Cancelled when the request's dispatch should stop: the client has gone away before it had the whole response, or the dispatch has used up its running time.

```csharp
public CancellationToken Aborted { get; }
```

## Remarks

Pass it to the asynchronous calls the handler makes, so that work nobody is waiting for stops.

Running time is the time a request dispatch spends executing. A request dispatch is the work Isoplane gives an instance to handle one request, described in [Units of work](../../../../../concepts/dotnet-runtime-differences.md#units-of-work). Time spent waiting for something the handler awaits, such as a database or another service, does not count. Once a dispatch has used its allowance and the token is cancelled, it has a short further period in which to finish; after that Isoplane stops the instance. A local session allows the most the platform offers. To see how the application behaves with less, set `occupancyMsPerDispatch` as [Try the application under tighter limits](../../../../../how-to/local-settings.md#try-the-application-under-tighter-limits) describes.
