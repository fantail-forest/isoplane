# DataProtectionKeys.UseConfiguredKeys method

Derives the keys from secrets in the application's settings, so every build given the same settings protects and unprotects with the same keys.

```csharp
public static IDataProtectionBuilder UseConfiguredKeys(this IDataProtectionBuilder builder,
    string section = "DataProtection:Keys")
```

| parameter | description |
| --- | --- |
| builder | What `AddDataProtection` returned. |
| section | The section holding the secrets, as `DataProtection:Keys:0`, `DataProtection:Keys:1` and so on. Each is at least 32 random bytes in Base64. The first protects new data and every one unprotects, so to replace a key, put the new secret first and remove the old one once nothing it protected is still in use. |

## Return Value

*builder*.

## Exceptions

| exception | condition |
| --- | --- |
| InvalidOperationException | Thrown when the application starts, if the section holds no secret or one that is not Base64 of at least 32 bytes. |

## Examples

```csharp
builder.Services.AddDataProtection().UseConfiguredKeys();
```

Create a secret for local development with `dotnet user-secrets set "DataProtection:Keys:0" "$(openssl rand -base64 48)"`.
