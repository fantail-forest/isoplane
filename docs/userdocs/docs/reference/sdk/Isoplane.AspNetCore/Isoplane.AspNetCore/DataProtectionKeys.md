# DataProtectionKeys class

Keeps ASP.NET Core Data Protection keys across template preparations. Without one of these, a key created during initialization is captured in the template and shared by its instances. Fresh initialization may create a different key; reusing a template retains its captured key. Data protected with an earlier key needs that key to remain readable.

## Remarks

The key stores ASP.NET Core ships for a database or another service, such as `PersistKeysToDbContext`, do not work in the sandbox: Data Protection reads and writes its keys synchronously, and an application cannot block on the network.
