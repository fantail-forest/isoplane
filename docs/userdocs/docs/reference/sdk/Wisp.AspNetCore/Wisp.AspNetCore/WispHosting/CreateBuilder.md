# WispHosting.CreateBuilder method

Creates an ASP.NET builder with host-provided runtime configuration and sandbox logging.

```csharp
public static WebApplicationBuilder CreateBuilder(string applicationName)
```

| parameter | description |
| --- | --- |
| applicationName | The assembly name used to discover application endpoints. |

## Return Value

A builder configured to receive requests from WISP without opening a listener.

## Remarks

The environment name is Production. Configuration files and environment variables are not loaded. Runtime configuration, including local User Secrets, becomes available after activation; resolve request-dependent settings through dependency injection rather than capturing them during preparation.
