# ApplicationOptions.Content property :since[next]

Files to give the application for this run, such as the templates or data files a test's expectations are written against. Empty by default.

```csharp
public IReadOnlyList<ContentSource> Content { get; init; }
```

## Remarks

The files join the content the application's project bundles, and the application reads them the same way. A file at the path of one of the project's replaces it, and of two sources that give the same path the later one wins. Nothing is written to the application's project directory, and the files apply only to the application this test starts.

The files count toward the application's package size and file limits, as the project's own do. [`StartAsync`](../IsoplaneApplication/StartAsync.md) builds the application's package from them, so a later change to a source file does not reach the running application.

## Examples

```csharp
var options = new ApplicationOptions
{
    Content =
    [
        new ContentDirectory(Path.Combine(AppContext.BaseDirectory, "Content")),
        new ContentFile("Knowledge/Articles/expenses.md", articlePath)
    ]
};
```
