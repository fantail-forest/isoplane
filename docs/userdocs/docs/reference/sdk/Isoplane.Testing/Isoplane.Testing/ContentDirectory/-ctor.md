# ContentDirectory constructor :since[next]

Every file in a directory on the test machine, each given to the application at its path relative to that directory.

```csharp
public ContentDirectory(string Directory)
```

| parameter | description |
| --- | --- |
| Directory | The directory to read, including its subdirectories. A relative path is resolved against the current directory, which varies between test runners, so build an absolute one from `AppContext.BaseDirectory`. |

## Remarks

Lay the directory out as the application's content root, so that a file at `Templates/welcome.html` beneath it is the application's `Templates/welcome.html`. To have the files beside the test assembly, include them in the test project with `CopyToOutputDirectory`. The directory is read where it is while [`StartAsync`](../IsoplaneApplication/StartAsync.md) builds the application's package, and is not copied.

## Examples

The files in the test project's `Content` directory, copied to its output:

```csharp
new ContentDirectory(Path.Combine(AppContext.BaseDirectory, "Content"))
```
