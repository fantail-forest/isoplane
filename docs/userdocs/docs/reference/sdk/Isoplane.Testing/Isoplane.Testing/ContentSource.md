# ContentSource record :since[next]

Files a test gives the application it starts, in [`Content`](./ApplicationOptions/Content.md). A source is either a [`ContentDirectory`](./ContentDirectory.md) or a [`ContentFile`](./ContentFile.md).

```csharp
public abstract record ContentSource
```

## Remarks

The application reads them as it reads the files its own project bundles, such as those in `wwwroot` or declared as `Content`. They are read-only, at paths beneath its content root.
