# launchSettings.json

`Properties/launchSettings.json` is the ordinary .NET file of launch profiles. `dotnet run` and `isoplane dev` read one profile from it when they start a local session. This page lists the keys Isoplane reads. It ignores every other key, such as `launchBrowser`. The key tables are generated from the list the Isoplane CLI parses, for the source version used to build this documentation.

[Supply local development settings](../how-to/local-settings.md) shows the file in use.

## Which profile is used

A local session uses the first profile whose `commandName` is `Project`. Select another with `dotnet run --launch-profile NAME` or `isoplane dev --launch-profile NAME`, or run without a profile with `--no-launch-profile`.

## Profile keys

| Key | Description |
| --- | --- |
| `commandName` | Must be `Project` for Isoplane to use the profile. Profiles with another value, such as `IISExpress`, are passed over. |
| `applicationUrl` | Sets the port a local session listens on: the port of the first `http` address. Separate several addresses with `;`. A local session serves plain HTTP on loopback, so the host name is not used and `https` addresses are passed over. |
| `environmentVariables` | An object whose entries become application settings. Two underscores in a name stand for a colon, so `Greeting__Default` is the setting `Greeting:Default`. `ASPNETCORE_ENVIRONMENT`, or `DOTNET_ENVIRONMENT`, names the environment of an ASP.NET application. |
| `isoplaneLimitsOverride` | An object that lowers the limits a local session runs with. Its keys are listed below. |

## Keys of `isoplaneLimitsOverride`

Each key is optional, and each value is a positive whole number. A local session otherwise uses the [local defaults](../concepts/resource-limits.md#local-defaults). [Resource limits](../concepts/resource-limits.md) explains what each limit measures.

| Key | Description |
| --- | --- |
| `memoryBytes` | The instance soft memory limit, in bytes, with a 25% hard-limit margin for finishing work. Must be a multiple of 65536. |
| `occupancyMsPerDispatch` | The running time one request may use, in milliseconds. Waiting does not count. Background work uses a separate instance allowance. |
| `concurrentConnectionsPerInstance` | The most outbound connections one instance may hold concurrently, including connections being opened and pooled connections. Closing a connection frees capacity. The host network ceiling still applies. |
| `pendingFuturesPerDispatch` | The most asynchronous operations one dispatch may have pending at once. |

## Example

```json
{
  "profiles": {
    "http": {
      "commandName": "Project",
      "applicationUrl": "http://localhost:5080",
      "environmentVariables": {
        "ASPNETCORE_ENVIRONMENT": "Development",
        "Greeting__Default": "world"
      },
      "isoplaneLimitsOverride": {
        "memoryBytes": 134217728,
        "occupancyMsPerDispatch": 1000
      }
    }
  }
}
```

## Comments

`dotnet run` does not accept comments in this file. A project created from an Isoplane template carries its notes in a property named `//`, which nothing reads.
