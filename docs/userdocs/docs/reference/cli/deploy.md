# isoplane deploy :since[next]

Prepare a bundle on this machine and select it for the next daemon start. Requires isoplaned on PATH.

```bash
isoplane deploy [options]
```

| Option | Description |
| --- | --- |
| `--local` :since[next] | Deploy on this machine; required. |
| `--config <config>` :since[next] | Required. Host configuration file. |
| `--app <app>` :since[next] | Required. Application name from the host configuration. |
| `--bundle <bundle>` :since[next] | Required. Portable application archive created by isoplane bundle. |
