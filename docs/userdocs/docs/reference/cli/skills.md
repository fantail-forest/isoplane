## isoplane skills install :since[next]

Write the isoplane skill for the Isoplane packages a project references into skills directories. With --dot-agents or --dot-claude, it goes where the skill already is at or above the project, and otherwise under the nearest directory at or above the project that holds a .git entry or a solution file. Asks which skills directories to use when no option names one.

```bash
isoplane skills install [options]
```

| Option | Description |
| --- | --- |
| `--project <project>` :since[next] | Project directory (default: current directory). The command restores the project first. |
| `--dot-agents` :since[next] | Install into .agents/skills, for agents that follow the Agent Skills convention. |
| `--dot-claude` :since[next] | Install into .claude/skills, for Claude Code. |
| `--skills-path <skills-path>` :since[next] | Install into this skills directory, such as .agents/skills or .claude/skills, relative to the current directory. The skill goes in its isoplane directory. |
| `--force` :since[next] | Overwrite files the skill would create that already exist. Without it, the command writes nothing when any exists. |
