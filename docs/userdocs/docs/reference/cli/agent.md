# isoplane agent :since[next]

Connect a coding agent to this machine's Isoplane tools.

```bash
isoplane agent <command>
```

| Command | Description |
| --- | --- |
| [`isoplane agent init`](#isoplane-agent-init) | Register the Isoplane MCP server in a coding agent's project configuration. |
| [`isoplane agent mcp`](#isoplane-agent-mcp) | Serve the Isoplane MCP server on standard input and output, for a coding agent to start. |

## isoplane agent init :since[next]

Register the Isoplane MCP server in a coding agent's project configuration.

```bash
isoplane agent init [options]
```

| Option | Description |
| --- | --- |
| `--harness <harness>` :since[next] | Required. The coding agent to configure; repeat for several: claude-code, codex, cursor, opencode, pi, copilot, vscode, antigravity, gemini. |
| `--directory <directory>` :since[next] | Directory whose configuration is written (default: current directory), usually the repository root. |

The file each harness's configuration is written to, relative to the directory:

| Harness | File |
| --- | --- |
| `claude-code` :since[next] | `.mcp.json` |
| `codex` :since[next] | `.codex/config.toml` |
| `cursor` :since[next] | `.cursor/mcp.json` |
| `opencode` :since[next] | `opencode.json` |
| `pi` :since[next] | `.pi/mcp.json` |
| `copilot` :since[next] | `.github/mcp.json` |
| `vscode` :since[next] | `.vscode/mcp.json` |
| `antigravity` :since[next] | `.agents/mcp_config.json` |
| `gemini` :since[next] | `.gemini/settings.json` |

## isoplane agent mcp :since[next]

Serve the Isoplane MCP server on standard input and output, for a coding agent to start.

```bash
isoplane agent mcp
```

The tools it offers:

| Tool | Description |
| --- | --- |
| `check_machine` :since[next] | Checks that this machine can build and run Isoplane applications: the .NET SDK, the native host library and the project templates. Returns the ready message, or an error saying what to install or run. |
| `start_session` :since[next] | Builds an Isoplane application project and runs it in the sandbox on this machine, as `isoplane dev` does. Returns the session's id and the address the application answers at. With watching on, a saved source change rebuilds and reloads it. A build that fails returns its errors and starts nothing. |
| `session_events` :since[next] | Returns what a session has reported since a given event number: ready and reloaded with the application's address, reload_pending, reload_failed and build_failed with their detail, and diagnostic for each line the application logged. Pass the last number seen to read only newer events; a wait of some seconds returns as soon as one arrives. |
| `stop_session` :since[next] | Stops a session started by start_session and frees its port. |
| `list_sessions` :since[next] | Lists the sessions started by start_session that are still running, with the project and address of each. |
