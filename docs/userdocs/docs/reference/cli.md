# CLI commands

The commands of the `isoplane` CLI, with the arguments and options of each. They are generated from the definitions the CLI parses with, for the source version used to build this documentation. `isoplane --help` and `isoplane <command> --help` print the same for the version you have installed; `isoplane --version` prints that version.

[Install the CLI](../how-to/install.md) describes installing it and setting up shell completion.

| Command | Description |
| --- | --- |
| [`isoplane dev`](cli/dev.md) | Run a local application. Launch settings supply the port and environment; --port overrides the port. |
| [`isoplane debug-adapter`](cli/debug-adapter.md) | Serve the Debug Adapter Protocol on standard input/output. |
| [`isoplane setup`](cli/setup.md) | Check prerequisites and install matching project templates. |
| [`isoplane uninstall-sdk`](cli/uninstall-sdk.md) | Remove everything setup installed, keeping the CLI. |
| [`isoplane cache`](cli/cache.md) | Manage compiled runtimes shared by local sessions. |
| [`isoplane prepare-runtime`](cli/prepare-runtime.md) | Compile a shared runtime into the local cache. |
| [`isoplane doctor`](cli/doctor.md) | Check this machine, or validate a WebAssembly module. |
| [`isoplane telemetry`](cli/telemetry.md) | Manage anonymous usage data. ISOPLANE_TELEMETRY_OPTOUT=1 or DO_NOT_TRACK=1 also disables it; ISOPLANE_TELEMETRY_DEBUG=1 prints events without sending them. |
| [`isoplane completions`](cli/completions.md) | Print a shell completion script. See the installation guide for shell setup. |
