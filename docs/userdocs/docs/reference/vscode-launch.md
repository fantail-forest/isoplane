# launch.json for VS Code

`.vscode/launch.json` holds the debug configurations Visual Studio Code offers when you press F5. The Isoplane Debugger extension adds the `isoplane` configuration type. This page lists the attributes of that type. The tables are generated from the extension's manifest.

[Debug an application](../debug-an-application.md) shows how to use these configurations.

## Launch

A configuration with `"request": "launch"` builds the application, starts it in a local session and attaches the debugger.

| Attribute | Value | Default | Description |
| --- | --- | --- | --- |
| `project` | string | required | Directory containing the Isoplane application project. |
| `configuration` | string | `Debug` | MSBuild configuration to compile for debugging. |
| `watch` | boolean | `true` | Rebuild source edits for the next request while keeping the debugger attached. |
| `port` | number |  | HTTP listener port. Use 0 to select an available port. |
| `cliPath` | string | `isoplane` | Path to the Isoplane CLI executable or assembly (.dll). |
| `console` | `integratedTerminal` or `internalConsole` | `integratedTerminal` | The integrated terminal keeps the application running after debugger detach; Ctrl+C stops it. |
| `sourceFileMap` | object |  | Map source directories recorded by the compiler to absolute local directories. |

```json
{
  "version": "0.2.0",
  "configurations": [
    {
      "name": "Debug local Isoplane",
      "type": "isoplane",
      "request": "launch",
      "project": "${workspaceFolder}",
      "configuration": "Debug"
    }
  ]
}
```

## Attach

A configuration with `"request": "attach"` attaches the debugger to a local debug session that is already running.

| Attribute | Value | Default | Description |
| --- | --- | --- | --- |
| `port` | number | required | Debugger port printed by the local Isoplane debug session. |
| `cliPath` | string | `isoplane` | Path to the Isoplane CLI executable or assembly (.dll). |
| `sourceFileMap` | object |  | Map source directories recorded by the compiler to absolute local directories. |
