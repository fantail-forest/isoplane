[explanation](../explanation/index.md).

|---|---|
| [Use the sandbox](use-the-sandbox.md) | Run anything under `scripts/dev`, expose ports, clean up |
| [Debug a rejected module](debug-a-rejected-module.md) | Find out which capability rule your module broke |
