Build and run a .NET application inside Isoplane's sandbox, using installed tools
and ordinary .NET commands.

1. [Install the Linux tools](install.md).
2. [Create an ASP.NET application](create-an-application.md), or
   [adapt an existing application](onboard-an-application.md).
3. [Build and run each configuration](run-and-rebuild.md).
4. [Supply local settings](local-settings.md) and [connect PostgreSQL](connect-postgresql.md).
5. [Test the application](test-an-application.md).

Read [the application lifecycle](application-lifecycle.md) before depending on
in-memory state or background work. If a step fails, use
[the troubleshooting guide](troubleshooting.md).
