# Isoplane native support

The native library that validates and runs applications in Isoplane's
WebAssembly sandbox on this platform. The
[Isoplane.Cli](https://www.nuget.org/packages/Isoplane.Cli) tool and the
[Isoplane.Testing](https://www.nuget.org/packages/Isoplane.Testing) package use
it; an application does not reference it directly.

Learn more at [isoplane.dev](https://isoplane.dev/).
