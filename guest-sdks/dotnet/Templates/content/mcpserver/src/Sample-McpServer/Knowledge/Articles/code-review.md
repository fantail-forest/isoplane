# Code review

Every change is reviewed by one other engineer before it merges.

- Open a pull request early and mark it as a draft until it is ready.
- Keep a change small enough to review in one sitting. Split refactoring from
  behaviour changes.
- The reviewer answers within one working day. If you cannot, say so and name
  someone who can.
- The author merges, once the checks pass and the reviewer has approved.
