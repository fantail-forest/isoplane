### Isoplane.AspNetCore.DataProtection.EntityFrameworkCore

Keeps ASP.NET Core Data Protection keys in the application's Entity Framework
Core database with `UseKeysFromDbContext`, so that cookies and antiforgery
tokens survive a rebuild.

- [Keep ASP.NET Core Data Protection keys across builds](https://isoplane.dev/docs/how-to/keep-data-protection-keys.md)
- [Isoplane.AspNetCore.DataProtection.EntityFrameworkCore API](https://isoplane.dev/docs/reference/sdk/Isoplane.AspNetCore.DataProtection.EntityFrameworkCore.md)
