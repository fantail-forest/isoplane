### Isoplane.Sdk

The sandbox, the SDK's entry points and types, local development, testing and
the tooling. Read `concepts/dotnet-runtime-differences.md` before changing
code that touches threads, the file system, time, networking or process APIs,
and `concepts/application-lifecycle.md` before deciding where state lives or
when work runs. `reference/api/Isoplane.Testing.md` is the package a test
project uses to start the application in the sandbox.
