### Isoplane.AspNetCore

ASP.NET Core hosting: bringing an existing application over, PostgreSQL,
Data Protection keys and scheduled work. The API page has `IsoplaneHosting`,
`DataProtectionKeys` and `SessionLoading`.

- [Bring an existing ASP.NET application](https://isoplane.dev/docs/how-to/onboard-an-application.md)
- [Connect to PostgreSQL](https://isoplane.dev/docs/how-to/connect-postgresql.md)
- [Keep ASP.NET Core Data Protection keys across builds](https://isoplane.dev/docs/how-to/keep-data-protection-keys.md)
- [Run work on a schedule](https://isoplane.dev/docs/how-to/run-work-on-a-schedule.md)
- [Isoplane.AspNetCore API](https://isoplane.dev/docs/reference/sdk/Isoplane.AspNetCore.md)
